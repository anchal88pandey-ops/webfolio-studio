# Webfolio Studio

Personal portfolio website service for students, freshers, job seekers, professionals, freelancers and creators in India.

**Founder:** Anchal Pandey
**Contact:** Anchal.Pandey.Connect@gmail.com

## Files

| File | Purpose |
|------|---------|
| `index.html` | Page structure and content |
| `styles.css` | All styling (responsive, light and navy theme) |
| `script.js` | Enquiry form: builds the email and opens Gmail compose |
| `README.md` | This guide |

No images, fonts or external libraries are used, so nothing else needs to be uploaded.

## Publish on GitHub Pages

1. Create a repository (for example `webfolio-studio`).
2. Upload `index.html`, `styles.css`, `script.js` and `README.md` to the **root** of the repository.
3. Go to **Settings > Pages**, choose **Deploy from a branch**, select `main` and `/ (root)`, then Save.
4. Your site will be live at `https://YOUR-USERNAME.github.io/webfolio-studio/` after a minute or two.

## Enquiry emails

- **Email Me**, **Email Webfolio Studio** and the footer address open a Gmail compose window to Anchal.Pandey.Connect@gmail.com.
- **Prepare enquiry email** fills the subject and message from the form, then opens Gmail compose. A fallback link opens the visitor's default mail app.
- Nothing is stored on the website. Enquiries reach you only when the visitor sends the email.
